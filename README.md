## Projeto em destaque

### Minha Dose — Aplicativo Mobile de Saúde

Aplicação multiplataforma desenvolvida para iOS e Android, com foco no acompanhamento e controle de vacinas.

O projeto reúne desenvolvimento mobile, integração com back-end, experiência do usuário, autenticação e organização de dados.

#### Principais responsabilidades

- Desenvolvimento da aplicação mobile com React Native e TypeScript;
- Criação de componentes modulares e reutilizáveis;
- Implementação de fluxos de navegação entre telas;
- Integração com APIs RESTful;
- Implementação de autenticação e validação de formulários;
- Gerenciamento de estado;
- Desenvolvimento de funcionalidades para agendamento e histórico;
- Investigação de compatibilidade entre iOS e Android;
- Aplicação de boas práticas de UX/UI;
- Utilização de IA para apoio à implementação, debugging e documentação técnica.

#### Resultado de usabilidade

O aplicativo alcançou **score 86,14 no System Usability Scale (SUS)**, classificação considerada **Excelente**.
